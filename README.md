# ManifestOS.studio

ManifestOS is a problem-first AI software creation studio. This repository is the initial architecture-first scaffold for the product.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - start the app locally
- `npm run build` - production build
- `npm run lint` - lint the app
- `npm run test` - run Vitest unit tests
- `npm run test:e2e` - run Playwright end-to-end tests

## Architecture-first workflow

Before code generation, the project must progress through a guided discovery pipeline and Blueprint stage. This scaffold includes the product architecture docs and a working demo shell to support the MVP journey.

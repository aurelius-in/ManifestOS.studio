# 00. Product Brief

## Product summary
ManifestOS.studio is a problem-first AI software creation studio that turns a real-world problem into a small, useful software app through guided discovery, planning, architecture, build, preview, and refinement.

## Mission
Anyone who can understand a problem should be able to build the software that solves it.

## Primary user
The default user is a nontechnical person describing a lived frustration or recurring task. They may not know technical terms and should not need a product spec to begin.

## Core promise
ManifestOS starts from the problem, not the app idea. It helps the user understand the issue, choose a direction, create a Blueprint, and generate a working preview.

## MVP outcomes
- accept a problem in plain language
- ask focused discovery questions
- produce a Problem Brief
- propose solution options
- choose a direction
- create the ordered Blueprint artifacts
- generate a build task graph
- create a working small web app preview
- refine through chat-based updates
- save versions and enable share/export

## Success signal
The user feels: “I did not even know I could make something like this.”

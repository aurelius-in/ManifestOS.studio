# 09. Testing Strategy

## Unit tests
- state transitions
- artifact invalidation
- Zod validation
- topological sorting of build tasks
- generated-file safety validation
- fixture AI behavior

## Integration tests
- problem to discovery
- solution proposal to selection
- blueprint generation sequence
- build creation and versioning
- refinement flow with artifact revalidation

## E2E
The golden path will validate the core experience: problem entry, discovery, solution choice, blueprint generation, build, preview, refinement, and export/share.
